# Maa Sharda Go - Driver Partner Web Application

A modern, responsive React + TypeScript delivery partner application rewritten from the Flutter codebase for **Maa Sharda Go** (GoDriver).

## Features

- **Authentication & Onboarding**:
  - Phone number login and registration with OTP verification
  - 4-step onboarding flow: Personal information & city selection, vehicle details, bank account details, and document upload
  - Application review screen with status polling and live review process checklist
- **Home Dashboard**:
  - Live Online / Offline toggle with real-time status indicator
  - Today's earnings and active orders counter
  - Radar map preview with GPS status
  - Weekly milestone incentive progress bar
  - High demand heat map surge alert with emergency SOS dialog
  - Available order requests list with 45-second countdown timers, instant accept/reject, sound chime and vibration alerts
- **Order Management & Active Delivery Flow**:
  - Active orders tracking with stage progression: *Heading to Restaurant* → *At Restaurant (Pickup OTP)* → *Heading to Customer* → *At Customer (Delivery OTP)* → *Delivered*
  - Order details checklist with quantities and items verification
  - One-tap Google Maps directions navigation
  - In-app Call and Chat contact actions
  - Delivery issue reporting sheet
  - Delivery history with status badges, earnings breakdown, and COD cash tracking
- **Earnings & Financials**:
  - Available balance display with instant cash-out simulation
  - Weekly Mon-Sun earnings bar chart
  - Today's breakdown: Base Pay, Tips, Surge & Incentives
  - Recent and all completed trips history
- **Partner Profile & Shift Attendance**:
  - Daily attendance shift check-in tracker with streak count
  - Profile customization: General info, Vehicle details, Bank details, Document verification
  - App settings: Order alerts, sound chime, haptic vibration, English & Hindi language switcher
  - 24/7 Helpline, FAQs, and Partner policies

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React Icons
